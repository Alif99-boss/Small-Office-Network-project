# Small Office Network Project

## Project Overview
A small office network designed and configured using Cisco Packet Tracer.

## Features
- VLAN 10 and VLAN 20
- DHCP configuration
- Inter-VLAN routing
- Default gateway configuration
- Network connectivity testing

## Devices Used
- Cisco 1841 Router
- Cisco 2960 Switch
- 6 PCs

## IP Addressing

### VLAN 10
- Network: 192.168.10.0/24
- Gateway: 192.168.10.1

### VLAN 20
- Network: 192.168.20.0/24
- Gateway: 192.168.20.1

## Testing
- DHCP configuration tested
- Gateway connectivity tested
- Same-VLAN communication tested
- Inter-VLAN communication tested

## Tool
- Cisco Packet Tracer
